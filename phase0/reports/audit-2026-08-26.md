consolidation commit: a document that *gains* a version hit an unguarded branch and raised

amend-then-rerun path the reporting rule prescribes, exercised for the first time.

Per the reporting rule, the checklist was executed once and the search stopped there. A fault
outside this model would be filed as `latent_regression` against Phase 1 and would amend the model
for the next audit; it would not reopen Phase 0.

## Caveat on M7

Recorded as *impossible* rather than *detected*. The divergence defect is removed by construction —
one home for the constant — which is stronger than detection. It does not cover an unauthorised
edit to the constant itself; that is a code-review and version-gate concern, and deriving the value
from the pinned `.tim` is Phase-1 work, filed rather than claimed.
